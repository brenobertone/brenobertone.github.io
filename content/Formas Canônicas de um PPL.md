# Formas Canônicas de um PPL
A forma canônica é quando temos: 
- um problema de maximização/minimização
- com x>=0 (sem mudar de sinal)
- restrições <=, >=

Isso se dá para evitar soluções triviais. 
Por exemplo, em um problema de maximização do lucro em uma fábrica, temos uma restrição no número de funcionários. 
Ela deve ser <=, caso contrário só teríamos infinitos funcionários

No problema de minimização de bugs, teríamos produção de código igual a zero.
