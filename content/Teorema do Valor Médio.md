# Teorema do Valor Médio
Seja $f$ uma função contínua. Todos os valores entre $f(a)$ e $f(b)$ são obtidos pela função.

Formalmente podemos descrever como:
$$\text{Seja }f:[a,b] \to \mathbb{R} \text{ contínua}$$
$$f(a) < d < f(b) \Rightarrow \exists c \text{ tal que } f(c) = d$$
