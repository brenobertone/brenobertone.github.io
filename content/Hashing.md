# Hashing
É uma estrutura que permite acessar os dados com tempo $O(1)$ no melhor caso, rápido nos casos médios e linear no pior caso.

Para isso, armazenamos os dados em um vetor, escolhemos uma [[Função de Hashing]], e acessamos o vetor nessa posição.

Idealmente, ela é bijetora mas na prática isso é díficil de ser encontrado. Assim surgem as [[Colisões de Hashing]].
