# Fronteira de Decisão
Em um problema de classificação binária:

É uma linha, curva ou hiperplano que divide o espaço em 2, cada região representando uma classe.

Para problemas de classificação multi-classe, podemos usar estratégias como [[One-vs-Rest]] e [[One-vs-One]]
