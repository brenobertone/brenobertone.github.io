# Rede Neural Recorrente
Modelo de rede mais utilizado para lidar com dados sequenciais. 

Funciona compartilhando os pesos $W_{aa}$ entre as camadas. Então, o input da n-ésima camada é a ativação da camada $n-1$ junto com o n-ésimo item da sequência.
