# Direção do Conjunto
Uma direção do conjunto é aquela que é sempre factível.
Sejam:
- Uma direção de conjunto $d$ 
- Um ponto factível $x_0$
Então $x_0 + \lambda d$ é factível $\forall \lambda$

OBS: Se a região factível é limitada, nenhuma direção é do conjunto
