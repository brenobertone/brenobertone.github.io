# Fórmula de Rodrigues
A Fórmula de Rodrigues é uma expressão usada para gerar uma sequência de polinômios ortogonais. Ela tem a forma:
$$P_n(x) = \frac{1}{w(x)} \frac{d^n}{dx^n} \left( w(x) \cdot f(x)^n \right)$$
Onde $w(x)$ é uma função de peso específica do sistema de polinômios
