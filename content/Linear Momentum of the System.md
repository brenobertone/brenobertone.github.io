# Linear Momentum of the System
In a closed system — that is, one without external forces — linear momentum is conserved.

$$p = m\dot{x}$$
$$\dot{p} = m\ddot{x} = F$$

The [[Center of Mass]] moves as if it was a single particle, with the total mass and momentum of the system. 

Its momentum changes as the sum of all external forces would act on that single particle.
