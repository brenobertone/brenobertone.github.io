# Identidade de Parseval
É quando temos a igualdade da [[Desigualdade de Bessel]]
Ela é necessária e suficiente para uma [[Série de Fourier]] convergir na média para uma função $f$
$$\frac{a_0^2}{2} + \sum_{n=1}^\infty a_n^2 + \sum_{n=1}^\infty b_n^2 = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)dx$$
