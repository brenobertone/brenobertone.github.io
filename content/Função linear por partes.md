# Função linear por partes
Uma função é linear por partes se pode ser escrita como:
$$
f(x)=a_ix + b_i
$$ Onde $a_i, b_i \in \mathbb{R}$ e $x_{i-1} <= x <= x_i$

Ela é convexa se sua "derivada" é crescente (como $x^2$)
Ela é côncava se sua "derivada" é crescente (como $-e^x$)
